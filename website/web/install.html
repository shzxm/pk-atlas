安装药时快捷指令

在快捷指令里记录服药、查看曲线文字摘要，或选择两种反算模型；计算由药时网站 API 完成。首次安装后编辑一次用户名和个人 API 密钥，之后运行无需重复输入。

iPhone 安装步骤
  1. 先在快捷面板的“个人 API 密钥”区域登录并点“生成或更换”，复制新密钥。已有密钥无法再次显示；重新生成会使旧密钥失效。
  2. 用 iPhone 的 Safari 点击下方“下载快捷指令文件”。
  3. 在 Safari 下载列表或“文件”App 的“下载项”中打开 yaoshi-text-v2.shortcut，添加这条快捷指令。安装后可自行重命名。
  4. 在「快捷指令」App 中点新添加的指令右上角的“…”进入编辑。开头的注释下面有两个“文本”动作：第一个把占位文字改为网站用户名，第二个改为个人 API 密钥。点“完成”保存。
  5. 以后直接点这条指令运行，选择记录服药、查看曲线文字摘要或两种反算；无需再输入账号和密钥。各选择菜单可点“返回上级”。

填写的是个人 API 密钥

请勿把网站登录密码写入快捷指令。若看到“用户名或访问密钥无效”，检查这两个文本动作是否已替换占位文字；重新生成密钥后，也要更新第二个文本动作。
