药时 API

快捷指令安装后，在开头的两个文本动作填写一次用户名和个人 API 密钥。密钥在快捷面板生成，仅显示一次。用户名用于定位账号；访问记录和计算结果还必须提供密钥。

查看快捷指令安装步骤
认证与格式
Authorization: Bearer <个人 API 密钥>
Content-Type: application/json

所有接口使用 HTTPS。GET 请求在查询参数中传 username，POST 请求在 JSON 正文中传 username。错误响应为 {"error":"原因"}；401 表示用户名或密钥无效。

接口
方法与路径参数结果
GET /api/v1/drugsusername支持的药物名称和 ID
GET /api/v1/dosesusername；可选 date=YYYY-MM-DD当天服用记录
POST /api/v1/dosesusername, drug, amount, unit；可选 time、idempotencyKey保存服用记录和 message
GET /api/v1/curveusername, drug；可选 date、stepMinutes完整采样点、nowText、caption；快捷指令只显示后两项
POST /api/v1/curve同上，改为 JSON 正文同上
POST /api/v1/curve.png同曲线 POST24 小时估算血药浓度 PNG 图；快捷指令文字模式无需调用
POST /api/v1/inverseusername, drug, mode, threshold, targetStart, holdHours；可选 count有限候选数学情景和文字摘要
POST /api/v1/inverse/pointusername, drug, mode, threshold, targetTime；可选 maxDose、count按目标时刻自动反算数学情景
GET /api/v1/stateusername账号完整状态

drug 可用 ID 或中文名称。unit 为 mg 或 g。time 与 targetStart 可用带时区 ISO 8601、Unix 毫秒，或当天的 HH:MM；未传服用时间默认为现在。mode 为 blood 或 equivalent。反算前需在网站保存药盒规格。

示例：保存服用
curl 'https://yao.shzxm.com/api/v1/doses' \
  -H 'Authorization: Bearer YOUR_KEY' \
  -H 'Content-Type: application/json' \
  --data '{"username":"YOUR_NAME","drug":"pregabalin","amount":25,"unit":"mg"}'
示例：获取曲线
curl 'https://yao.shzxm.com/api/v1/curve?username=YOUR_NAME&drug=pregabalin' \
  -H 'Authorization: Bearer YOUR_KEY'
药时使用群体药代教学模型。曲线不是实测血药浓度；反算结果不是服药建议。
